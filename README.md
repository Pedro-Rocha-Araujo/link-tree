## 🧩 ❓ Características do projeto :
O presente projeto é um gerenciador de links, que permite organizar seus links e compartilhha-los para a visualização de terceiros. O projeto foi desenvolvido com abordagem Mobile-first e mensagens de feedback para melhor compreensão do usuário.

## 🔧 📖 Texnologias e bibliotecas usadas :
* Next.js
* Typescript
* Firebase
* React-Toastify
* Cookies-JS

## ⚙️ Funcionalidades
* Login e Cadastro de Usuário
* Criação de uma página personalizada com seus links
* Exclusão de links adicionados
